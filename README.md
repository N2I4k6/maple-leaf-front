# 🍁 Maple Leaf — Frontend

## 📖 О проекте

Публичный сайт для просмотра мультсериалов. Каталог с постерами и рейтингом, страница сериала со списком сезонов и серий, видеоплеер с выбором озвучки, новости платформы, светлая и тёмная темы. Данные получает по REST API бэкенда.

## 🛠 Стек

- React
- TypeScript
- Vite
- React Router
- Ant Design
- axios
- Sass
- react-player
